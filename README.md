# rvt-starter-v4 🚀

A modern React + Vite + Tailwind CSS v4 starter template — lightweight, fast, and ready for rapid development.

---

## 🛠️ Stack

-   ⚛️ **React** (with JSX support)
-   ⚡ **Vite** (super fast dev server & bundler)
-   🎨 **Tailwind CSS v4** (next-gen utility-first CSS)
-   🧪 **PostCSS & Autoprefixer**

---

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/your-username/rvt-starter-v4.git

# Navigate into the project
cd rvt-starter-v4

# Install dependencies
npm install

# Start development server
npm run dev
```
